# Moteurs natifs

Le moteur CPU de développement est llama.cpp b11681. L'archive est vérifiée
contre le SHA-256 publié par GitHub. Les exécutables fournis dans l'archive
ne seront pas tous livrés : seul le moteur nécessaire et ses DLL auditées
doivent entrer dans le futur installateur. Les serveurs réseau et utilitaires
inutilisés seront exclus du produit.

Aucune pile CUDA ni Vulkan n'est encore empaquetée ou validée.
